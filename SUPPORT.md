# Getting help

OpenDock is a community project maintained by volunteers. Here's where to go.

| You want to… | Go to |
| --- | --- |
| Install, uninstall or configure OpenDock | [Installation guide](docs/installation.md) and the [user guide](docs/user-guide.md) |
| Get your Windows taskbar back | [Recovering the taskbar](docs/installation.md#recovering-the-windows-taskbar) |
| Ask a question or share your layout | [GitHub Discussions](https://github.com/isaacobenzy/OpenDock/discussions) |
| Report a bug | [Bug report form](https://github.com/isaacobenzy/OpenDock/issues/new?template=bug_report.yml) |
| Request a feature or widget | [Feature](https://github.com/isaacobenzy/OpenDock/issues/new?template=feature_request.yml) or [widget](https://github.com/isaacobenzy/OpenDock/issues/new?template=widget_request.yml) request |
| Report a security problem | Privately, as described in [SECURITY.md](SECURITY.md) |
| Contribute | [CONTRIBUTING.md](CONTRIBUTING.md) |

Before opening an issue, please search existing issues; a 👍 reaction on an existing one helps us prioritise more than a duplicate.

There is no paid support. Please don't contact maintainers privately for general help; public answers help everyone who has the same question.
